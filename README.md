# HurlingSports

Tienda online de zapatillas urbanas y deportivas desarrollada como Trabajo Práctico N°1 para la materia **Construcción de Interfaces de Usuario** - Universidad Nacional de Hurlingham (UNAHUR) 2026.

## Descripción

Aplicación web que simula una tienda de zapatillas. Los usuarios pueden explorar el catálogo, filtrar productos por categoría y precio, ver el detalle de cada modelo, elegir talle y agregar productos al carrito de compras.

## Tecnologías utilizadas

- [React 19](https://react.dev/)
- [Vite 5](https://vitejs.dev/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [React Router v7](https://reactrouter.com/)

## Instrucciones para instalar y correr el proyecto

```bash
# 1. Clonar el repositorio
git clone https://github.com/tp-tienda-unahur/tienda-online-tp

# 2. Ingresar a la carpeta del proyecto
cd tienda-online-tp

# 3. Instalar dependencias
npm install

# 4. Correr en modo desarrollo
npm run dev
```

Abrí [http://localhost:5173](http://localhost:5173) en el navegador.
